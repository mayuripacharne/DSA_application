# Algorithm

Step 1: Start the program.

Step 2: Define a structure Student containing:
Roll Number
Name
Branch
Marks
Pointer next

Step 3: Initialize head = NULL.

Step 4: Create a new student node dynamically.

Step 5: Accept Roll Number, Name, Branch and Marks from the user.

Step 6: If the linked list is empty, make the new node the head.

Step 7: Otherwise, traverse the list and add the new node at the end

Step 8: To display records, start from head and traverse the linked list.

Step 9: Display the details of each student.

Step 10: Stop the program.
