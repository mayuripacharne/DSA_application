#Algorithm
Step 1: Start the program.
Step 2: Display the main menu.
Step 3: Accept the user's choice.
Step 4: Perform the selected operation:
Add a student record.
Display all student records.
Search for a student by roll number.
Update student details.
Delete a student record.
Navigate forward and backward using a Doubly Linked List.
Schedule student turns using a Circular Linked List.
Calculate grades, class average, and highest marks.
Compare linked lists with their time and space complexities.
Step 5: Display the result of the selected operation.
Step 6: Return to the main menu if the user has not selected Exit.
Step 7: Stop the program when the user selects Exit.
