#ALGORITHM

 Start the program.
 
Define the transport stops as vertices.

Represent the routes and their distances using a weighted adjacency matrix.

Apply Prim’s algorithm to find the Minimum Spanning Tree.

Display the selected edges and total MST cost.

Check whether all vertices are connected.

Select the source and destination stops.

Apply Dijkstra’s algorithm to calculate the shortest distance.

Display the shortest route and its total distance.

If the destination is unreachable, display an appropriate message.

Stop the program.
