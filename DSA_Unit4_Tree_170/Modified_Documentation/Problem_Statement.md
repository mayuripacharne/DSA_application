# Problem Statement

Implement an AVL Tree Traversal System using C++ to construct a self-balancing binary search tree from user-entered integers.
The system should perform inorder, preorder, postorder, and level-order traversals while displaying the balance factor of each node.
It should also allow users to insert additional values, automatically update the tree structure and traversals, and verify whether the
inorder traversal is in sorted order by displaying PASS or FAIL.
